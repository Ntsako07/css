# Vicky's Cake City

A modern, elegant bakery website for a premium custom cake business. This project showcases Vicky's Cake City brand, product offerings, business information, and customer enquiry flow using static HTML and CSS.

## Overview

Vicky's Cake City is a local cake studio offering bespoke cakes for weddings, birthdays, corporate events, and special occasions. This website is designed to present the business professionally, attract customers, and make it easy for visitors to enquire about custom orders.

## Features

- Landing page with strong brand messaging and call-to-action
- About page highlighting the bakery's story, mission, vision, and team
- Products page showcasing signature cake categories and features
- Enquiry form for customers to request custom cake details
- Contact page with business locations, hours, and contact information
- Embedded Google Maps for storefront locations
- Responsive styling for desktop and mobile viewing

## Project Structure

- `index.html` – homepage
- `about.html` – brand story and team information
- `products.html` – catalogue of available cake categories
- `enquiry.html` – customer enquiry form
- `contact.html` – contact details and business locations
- `style.css` – all styling for the website
- `images/` – brand assets and product images

## Technologies Used

- HTML5
- CSS3
- Google Maps Embed

## How to Run the Website

Open `index.html` directly in a web browser. Use the navigation menu to move between the Home, About Us, Products, Enquiry, and Contact pages.

## Notes

This is a front-end static website. It does not include a database or live form-processing service, so form submissions are currently designed for visual/demo purposes.
