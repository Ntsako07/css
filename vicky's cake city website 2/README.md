# Vicky's Cake City

A polished, multi-page bakery website for a premium custom cake studio. This project presents the brand, product range, enquiry process, and contact details in a clean, responsive layout built with static HTML, CSS, and JavaScript.

## Overview

Vicky's Cake City is a boutique cake business creating bespoke cakes for weddings, birthdays, corporate events, and other special occasions. The website is designed to help customers browse products, learn about the brand, and submit cake enquiries with ease.

## Features

- Elegant landing page with clear brand messaging and call-to-action
- About page covering the bakery story, values, and service offering
- Product catalogue highlighting wedding, birthday, mini cake, and custom options
- Enquiry form for custom cake requests
- Contact page with business details and location information
- Responsive design for desktops, tablets, and mobile devices
- Simple front-end interactions and smooth on-page navigation

## Project Structure

- `index.html` – homepage and brand introduction
- `about.html` – story, mission, and business background
- `products.html` – product categories and descriptions
- `enquiry.html` – customer enquiry form
- `contact.html` – contact details and location information
- `style.css` – all site styling and responsive layout rules
- `java/script.js` – client-side JavaScript for menu and page interactions
- `images/` – product and brand imagery
- `robots.txt` and `sitemap.xml` – basic SEO/site metadata files

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Responsive web design
- SEO-related metadata files

## How to Run the Website

Because this is a static site, there is no install step required.

Option 1:
- Open `index.html` directly in your browser.

Option 2 (recommended for local preview):
- From the project folder, run:
  `python -m http.server 8000`
- Then open `http://localhost:8000` in your browser.

## Notes

This is a front-end static website and does not currently connect to a backend or database. The enquiry form is intended for front-end demonstration and can later be connected to email, a CRM, or a server-side form handler.
