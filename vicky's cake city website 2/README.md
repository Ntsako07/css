## Project Overview

Vicky's Cake City is a fictional bakery brand created to showcase a premium cake design and custom celebration service. The project focuses on building a modern, responsive website that promotes the brand, highlights the cake collections, and provides an online enquiry channel for customers.

The website is designed to help potential customers explore the business story, view available cake options, and contact the bakery for personalised orders. The goal is to create a clean digital experience that reflects the elegance and creativity of the brand while ensuring ease of navigation across devices.

## Website Goals and Objectives

- Promote the Vicky's Cake City brand and create a professional online presence
- Showcase bakery services, cake collections, and unique custom order options
- Provide users with clear information about the business and its values
- Make it easy for customers to submit enquiry requests
- Deliver a responsive website that works well on desktop, tablet, and mobile devices
- Improve user engagement through structured content and user-friendly design
- Demonstrate front-end web development skills using HTML, CSS, and JavaScript

## Key Features and Functionality

- Responsive multi-page layout for a seamless browsing experience
- Homepage hero section with clear brand message and call-to-action buttons
- About page explaining the origin, mission, and vision of the bakery
- Product page featuring cake categories such as wedding, birthday, mini, and custom cakes
- Enquiry form for customers to request custom cake details
- Contact page with business information and communication details
- Navigation bar for easy access to all main pages
- Styled visual design consistent with a premium bakery brand
- Simple interactive JavaScript features to improve usability
- SEO-related metadata for better online discoverability

## Project Structure

- `index.html` – Home page
- `about.html` – Business story, mission, and vision
- `products.html` – Product offerings and cake categories
- `enquiry.html` – Enquiry form for custom orders
- `contact.html` – Contact information and location details
- `style.css` – Main styling and responsive layout
- `java/script.js` – JavaScript interactions and dynamic page behaviour
- `images/` – Project visual assets
- `robots.txt` and `sitemap.xml` – Website metadata and indexing support
